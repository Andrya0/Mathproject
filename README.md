# Матемсок

Сайт для быстрого повторения теории перед математическими олимпиадами. В каталоге 20 коротких конспектов по алгебре, геометрии, теории чисел и комбинаторике.

## Как открыть

Скачайте репозиторий и откройте `index.html` в браузере. Сборка и доступ к интернету не требуются.

## Возможности

- Поиск и фильтрация конспектов по разделам.
- Пометки и личный список тем для повторения.
- Админ-панель для добавления, изменения и удаления тем.

Пометки, списки и изменения тем сохраняются в браузере на текущем устройстве. Демонстрационный код админ-панели: `math11`.
